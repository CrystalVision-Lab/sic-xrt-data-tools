# 웨이퍼 단위 개발 코호트 v1

`development_cohort.build`는 제공자 점 중 W1/2/9만 읽어 `samples.csv`와 raw RGB
128×128 TIFF를 생성한다. W8 영상은 열지 않는다. W2 TSD는 기존 전 픽셀 반전
증거의 파일/디코딩 해시와 원본 ROI 좌표를 검증한 뒤 알려진 좌표 보정을 먼저 적용한다.

기존 품질 임계값과 AI 보류/불일치는 유지한다. 중심 32픽셀 사각형 안에 다른 종류의
ROI가 있으면 제외하며, 128픽셀 문맥의 바깥 부분에만 있으면 개수를 기록해 허용한다.
주변 특징이 곧 표적의 라벨을 의미하지 않으며 ROI 누락을 완전히 검출하는 규칙도 아니다.
제공자 라벨을 수정하거나 새 물리적 정답을 추측해 확정하지 않는다.

계약 `wafer_grouped_development_cohort` v1은 manifest SHA256, 클래스 순서,
허용/금지 웨이퍼, 원본 좌표 근거, 품질 규칙과 연구 라벨 출처를 담는다. 모든 row의
split은 `development`이다. 기존 train/val/test 로더에 넣으면 안 된다. 소비자는 W1/2/9를
그룹으로 나눠 전체 웨이퍼를 보류하며 같은 웨이퍼의 전후 자료를 나누지 않아야 한다.
모델 선택에 활용하는 개발 평가이며 독립 최종 시험이 아니다.

이번 결과는 8,962개로 기존 W1/2/9 7,483개에서 1,479개 증가했다. 기존 표본은 모두
포함한다. BPD는 W1 159개, W2 38개(합계 197개)이며 18개가 추가됐다. W9에는
제공자 BPD가 없고 W3~7에는 제공자 점이 없으므로 데이터 보강의 범위에 한계가 있다.
추가 BPD 18개의 그림은 AI가 확인했으나 전문가 정답으로 승격하지 않았다.

실제 데이터·검토 그림은 로컬에만 저장한다. ML 소비자: CrystalVision-Lab/sic-xrt-ml#23.
