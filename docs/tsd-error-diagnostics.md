# TSD 오분류 원본 진단

관련 Issue #19. 소비자 학습 비교는 [ML #13](https://github.com/CrystalVision-Lab/sic-xrt-ml/issues/13)에서 수행한다.
기존 `ai_visual_review.prepare(context_size=512)`와 `finalize`를 사용했으며 생산자 코드는 변경하지 않았다.

2026-10-04 기존 균형438 모델의 검증 결과에서 제공자 TSD/모델 TED인57건을 모두 선택했다.
원본 판독 패널4장과 각512픽셀 원본 문맥을 생성해 실제로 확인했다.
원본이 uint8 RGB여서 각512 문맥에서 잘라낸128 입력을 기존 모델 TIFF와 픽셀 단위로 비교했고57건 모두 같았다.
패치 생성 과정에서 좌표 이동이나 표시용 스트레치가 입력에 추가된 사례는 없었다.

57건 모두 지정 좌표의 형태가 배경과 구분하기 어렵거나 인접한 강한 대비 대상과 관계가 불명확해
진단상 보류했다. 인접 원형의 위치가 달라 보인다는 관찰만으로 제공자 좌표/라벨 오류를 확정하지 않았다.
현재의 단일 영상 문맥으로 물리적 TED/TSD 정답을 확정하거나 모델 오분류를 확정할 수 없다.
검수 표시 이름은 양희승, 실제 판독은 Codex_AI이며 사람·전문가 정답 확인은0건이다.

| 산출물 계약 | 의미 |
|---|---|
| review_priority_plan v1 | 정확한57개 point_id, workspace/candidate 해시, 선택 근거와 기존 예측·체크포인트 해시 |
| ai_visual_review_panels v1 | 기존좌표, 원본 patch 해시,512문맥과 표시 전용 회색조 스트레치 |
| ai_visual_type_proposals v1 |57건 hold, proposed_base_label=null, human/expert/verified evaluation=false |
| diagnostic_scope.json | 오류 집단 선택을 AI가 알고 있음, 독립 블라인드 검증 아님, 입력-원본 픽셀 일치57건 |
| output_hashes.json | 생성 파일 해시 |

화면에서 라벨을 숨겼더라도 AI는 선택 기준을 알았다. 선택된 오류 집단의 보류 비율은 전체 데이터의
라벨 오류율, 좌표 오류율 또는 타입 판독 정확도가 아니다.
이 결과는 진단용이며 고정된 연구 dataset의 라벨·좌표·선택에 반영하지 않았다.
소비자는 원래 검증360개와 원래 학습7,123개를 유지한다.
향후 dataset을 다시 만들 때 이 진단 배치를 일반 정답 검수 결과로 자동 적용하지 않는다.

비오분류 대조군13개(기존 모델 TSD10/BPD3)의128 입력도 별도 화면에서 살펴봤다.
대조군의 일부는 원형 밝은 대상이 더 분명하게 보였지만 이는 모델의 대비/형태 의존 가설을
점검하는 관찰이며 독립 실험이나 물리 타입의 확정 근거가 아니다.
원본 영상, ROI, 기존 검수 배치, 사람 검수 세션 및 학습 dataset은 보존했다.
실제 이미지·좌표별 진단·모델 파일은 Git에 포함하지 않는다.
