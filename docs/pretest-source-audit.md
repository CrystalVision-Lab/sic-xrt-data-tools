# 최종 시험 전 원본·ROI 감사

`pretest_audit.audit_source_rows`는 **학습 분할**의 원본 파일 해시, ROI 점 좌표,
제공자 종류, crop bounds, TIFF 패치 해시와 모든 픽셀을 검사한다. 연구 데이터셋
생성기의 Python `round`(ties-to-even)를 그대로 사용한다. 다른 좌표 반올림 규칙을
임의로 혼용하지 않는다. 원본이나 라벨을 변경하지 않는다.

`orientation_probe`는 원래 좌표와 좌우/상하/180도 반전, 일정 이동 대조군의 국소
대비를 비교한다. 전수 또는 고정 간격 표본을 사용하며 모델 예측으로 표본을 고르지
않는다. 대비가 높다는 이유만으로 변환이나 타입 변경을 승인하지 않는다.

소비자 계약은 `pretest_source_audit`, schema version 1이다. 데이터 manifest SHA256,
`source_pixel_and_roi_checks_passed`, `research_test_permitted`, 학습 점검 수,
라벨/좌표 변경 여부, 한계 및 첨부 감사 파일의 SHA256을 포함한다. ML 소비자는
manifest와 첨부 파일 해시를 확인해야 한다. 전문가 정답 확인을 뜻하지 않는다.

이번 감사에서는 학습 7개 영상의 7,123개 패치와 검증 불일치 10건을 확인했다.
추가로 확정된 좌표 오류나 라벨 수정은 없다. 전체 원본 일부의 색띠는 남아 있으나
선택된 학습 패치 7,123개를 기존 품질 규칙으로 재검사한 결과 경고는 0건이었다.
약한 대비, 긴 선 끝부분, 주변 결함이 있는 10건은 제공자 라벨을 유지했다.
사람 검수 이력을 만들지 않았으며 실제 자료·그림·감사 결과는 로컬에만 저장한다.

ML 소비 및 1회 시험: CrystalVision-Lab/sic-xrt-ml#21.
