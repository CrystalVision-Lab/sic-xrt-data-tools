# 제공 좌표의 가져오기·전달 감사

`reference_audit`는 가져온 좌표가 원본 ROI와 같은지, 평가 프레임에 보정이 정확히 반영됐는지만 확인한다. 결함 타입의 물리적 정답이나 전체 결함 주석 완전성을 승인하지 않는다.

`audit_roi_import`는 해시를 확인한 원본 ROI를 읽는 콜백을 받아 index별 좌표·누락·중복을 대조한다. 선택된 ROI 파일에 대한 보존 검사이며, 잘못된 영상 연결이나 제공되지 않은 주석을 복구하는 기능은 아니다.

`audit_frame`은 대상 영상 해시를 강제하고 좌우 반전 또는 점별 기존 보정을 적용해 기준 좌표를 재구성한다. old_xy와 subtype이 다르면 이중 보정 또는 출처 불일치로 거부한다. 이미지 경계 때문에 128px 패치를 만들 수 없는 점의 제외와 실제 내부 점 누락을 분리한다. 웨이퍼 8은 허용하지 않는다.

출력은 감사용 보고서이며 학습 라벨을 변경하지 않는다. 원본 ROI 좌표 전부가 보존됐더라도 미대응 검출점을 자동 배경으로 분류해서는 안 된다. 관련 모델 점수 진단은 [ML #39](https://github.com/CrystalVision-Lab/sic-xrt-ml/issues/39)에서 수행한다.
